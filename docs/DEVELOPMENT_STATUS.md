# وضعیت توسعهٔ ساهر

این سند وضعیت نسخهٔ جدید با گردش کار چهارمرحله‌ای را شرح می‌دهد. ادعاهای نسخهٔ پیشین دربارهٔ صف کارگر، جست‌وجوی صفحه‌محور یا گزارش کاربران، معیار قابلیت‌های فعال این نسخه نیستند.

| قابلیت | وضعیت فعلی |
|---|---|
| ثبت فایل همراه منبع و مجوز | پیاده‌سازی شده؛ سقف ۲۵ مگابایت |
| رابط چهارمرحله‌ای و تاریخچهٔ اقدامات | پیاده‌سازی شده |
| نگهداری اصل فایل و داده در فضای پایدار | پیاده‌سازی شده |
| استخراج متن و متن‌خوانی تصویر | به استخراج‌کننده‌های موجود متصل است؛ همهٔ قالب‌ها در چرخهٔ جدید آزموده نشده‌اند |
| جلوگیری از تعارض و عبور زودهنگام | پیاده‌سازی و در آزمون یکپارچه بررسی شده |
| بررسی سلامت و حریم خصوصی | ثبت دستی؛ قرنطینه، ضدبدافزار و پوشاندن خودکار ساخته نشده‌اند |
| دسته‌بندی و ثبت شواهد و ابهام‌ها | دستی؛ دسته‌بندی خودکار ساخته نشده است |
| اتصال به پرونده یا رویداد | فقط نام متنی؛ موجودیت مستقل و تطبیق خودکار ساخته نشده‌اند |
| تکمیل از منابع عمومی | ثبت دستی شواهد؛ جست‌وجوی برخط ساخته نشده است |
| سنجش اطمینان و آستانهٔ بازبینی | ساخته نشده است |
| قالب و تصمیم بازبین | ثبت دستی؛ بدون احراز هویت یا صف نقش‌محور |
| دریافت گزارش | خروجی ساختاریافته؛ سند نهایی ورد ساخته نشده است |
| تنظیمات منابع، گروه‌ها، برچسب‌ها و قالب‌ها | مدیریت قابل‌ویرایش ساخته نشده است |
| دسترسی چندکاربره و زمان نگهداری | ساخته نشده است |
| صدا و ویدئو | ثبت فایل ممکن است؛ پیاده‌سازی خودکار متن‌خوانی صدا و تحلیل ویدئو وجود ندارد |

## شواهد آزمون نسخهٔ جایگزین

در اجرای قبلی، ساخت رابط موفق بود و آزمون یکپارچهٔ گردش کار گذشت. آزمون، ثبت اولیه، محدودیت انتقال، تعارض نسخه، استخراج فایل متنی، الزام بازبینی، خروجی و ماندگاری را پوشش داد. خدمات کانتینری سالم بودند و صفحهٔ خالی چهارمرحله‌ای در مرورگر مشاهده شد. این شواهد به معنی آزمون تمام قالب‌های فایل یا اجرای کامل نمودار هدف نیستند.

در این نوبت فقط مستندات تغییر کرده‌اند؛ نتیجهٔ آزمون‌های بالا مربوط به اجرای نسخهٔ جایگزین است.

```sh
npm run build
python -m pytest tests/test_workflow_reset.py -q
```

## ترتیب پیشنهادی تکمیل

۱. تعریف موجودیت مستقل پرونده و رویداد و امکان اتصال واقعی محتوا.
۲. افزودن ورود کاربران، نقش بازبین و کنترل دسترسی.
۳. اجرای واقعی بررسی سلامت و حفاظت اطلاعات پیش از تحلیل.
۴. تنظیمات قابل‌ویرایش منابع، موضوع‌ها، قالب‌ها و آستانه‌ها.
۵. تکمیل اطلاعات با منابع قابل ردیابی و بازبینی انسانی.
۶. گزارش‌های اختصاصی، سابقهٔ دقیق تغییر فیلدها و قواعد نگهداری.

نمودار هدف در [سند گردش کار](WORKFLOW.md) آمده است. تصویر مرجع کاربر نیز برای مقایسه نگهداری شده است.
