# وضعیت توسعهٔ ساهر

نسخهٔ `workflow-4`: ورود گروهی تا ۱۰۰۰ عکس در هر نوبت، اسکن هر فایل، متن‌خوانی و پیشنهاد آی‌دی، اتصال با تأیید کاربر و پوشهٔ مستقل حساب در شبکه و محدودهٔ دسترسی پیاده‌سازی شده‌اند. صفحهٔ اصلی به پوشه‌های حساب تغییر کرده است. ۲۱ آزمون موفق بودند، شامل متن‌خوانی واقعی سه عکس و ادغام دو مرجع همسان اینستاگرام و جداسازی مرجع تلگرام. موضوع عکس فعلاً دستی انتخاب می‌شود؛ دسته‌بندی خودکار موضوعی و فهرست دقیق ۱۲ دسته هنوز تکمیل نشده‌اند. [راهنمای جریان جدید](ACCOUNT_IMPORT.md).

تکمیل امنیت فایل و دسترسی: ۱۶ آزمون گردش کار، کنترل دسترسی و امنیت موفق بودند؛ سه آزمون از ClamAV و مدل‌های واقعی استفاده کردند. فایل سالم و EICAR بررسی شدند، چهره و پلاک در دو نمونهٔ واقعی تشخیص داده شدند و گزارش Word فقط تصویر پوشانده‌شده را در خود داشت. ساخت TypeScript/Vite موفق بود و نسخهٔ `workflow-3` در Docker اجرا شد. راهنمای استفاده و محدودیت‌ها در [امنیت فایل و دسترسی](FILE_SECURITY.md) است.

این سند وضعیت نسخهٔ جدید با گردش کار چهارمرحله‌ای را شرح می‌دهد. ادعاهای نسخهٔ پیشین دربارهٔ صف کارگر، جست‌وجوی صفحه‌محور یا گزارش کاربران، معیار قابلیت‌های فعال این نسخه نیستند.

## شواهد آزمون نسخهٔ جایگزین

در اجرای قبلی، ساخت رابط موفق بود و آزمون یکپارچهٔ گردش کار گذشت. آزمون، ثبت اولیه، محدودیت انتقال، تعارض نسخه، استخراج فایل متنی، الزام بازبینی، خروجی و ماندگاری را پوشش داد. خدمات کانتینری سالم بودند و صفحهٔ خالی چهارمرحله‌ای در مرورگر مشاهده شد. این شواهد به معنی آزمون تمام قالب‌های فایل یا اجرای کامل نمودار هدف نیستند.

آزمون گردش کار اکنون ورود کاربران، محدودیت نقش ویرایشگر، دسترسی مدیر به تنظیمات، ابطال نشست، دریافت اصل فایل و خواندن خروجی Word را نیز پوشش می‌دهد.
آزمون اتصال آنلاین از پاسخ شبیه‌سازی‌شده استفاده می‌کند. اعتبار کلیدها، مدل انتخابی، هزینه و دسترسی شبکه باید با حساب واقعی ارائه‌دهنده بررسی شوند.

```sh
npm run build
python -m pytest tests/test_workflow_reset.py -q
```

## ترتیب پیشنهادی تکمیل

۱. تکمیل دسترسی در سطح پرونده و مدیریت چرخهٔ عمر کاربران.
۲. اجرای واقعی بررسی سلامت و حفاظت اطلاعات پیش از تحلیل.
۳. گروه‌ها، برچسب‌ها و آستانه‌های قابل‌تنظیم.
۴. تکمیل اطلاعات با منابع قابل ردیابی و بازبینی انسانی.
۵. گزارش‌های اختصاصی، سابقهٔ دقیق تغییر فیلدها و قواعد نگهداری.

نمودار هدف در [سند گردش کار](WORKFLOW.md) آمده است. تصویر مرجع کاربر نیز برای مقایسه نگهداری شده است.
