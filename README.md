# ساهر؛ گردش کار محتوا

صفحهٔ اصلی، پوشه‌های حساب‌ها و ورود گروهی عکس‌ها را نمایش می‌دهد. متن عکس‌ها خوانده می‌شود و آی‌دی‌های قابل‌مشاهده برای تأیید اتصال پیشنهاد می‌شوند. موضوع عکس داخل پوشهٔ حساب ثبت می‌شود. گردش چهارمرحله‌ای برای بازبینی و خروجی همچنان در بخش جداگانه در دسترس است. [راهنمای ورود گروهی و پوشه‌ها](docs/ACCOUNT_IMPORT.md).

## اجرا

در ریشهٔ پروژه اجرا کنید.

```sh
docker compose up -d --build --wait
```

نشانی برنامه در اجرای محلی به شکل زیر است.

```text
http://127.0.0.1:8730/
```

## مسیر فعلی

۱. فایل همراه منبع و مجوز پردازش ثبت می‌شود.
۲. کاربر نتیجهٔ بررسی سلامت و حریم خصوصی را ثبت می‌کند و متن را استخراج یا دستی وارد می‌کند.
۳. موضوع، شواهد و موارد نامشخص ثبت می‌شوند. کاربر می‌تواند پرونده یا رویداد را ایجاد کند یا محتوا را به موردی موجود پیوند دهد.
۴. قالب بررسی و دلیل تصمیم با هویت کاربر بازبین ذخیره می‌شوند و گزارش JSON و Word قابل دریافت است.

در نخستین ورود، نام کاربری مدیر و گذرواژهٔ حداقل ۱۲ نویسه‌ای تعیین می‌شود. مدیر از بخش تنظیمات می‌تواند موضوع‌ها، منابع پیشنهادی و مسیرهای بازبینی را ویرایش کند و کاربر با نقش مدیر، بازبین یا ویرایشگر بسازد. ثبت تصمیم به نقش مدیر یا بازبین نیاز دارد. نشست ورود پس از هشت ساعت منقضی می‌شود.

اصل فایل، متن، مشخصات و تاریخچهٔ تغییرات در فضای پایدار داکر نگهداری می‌شوند. نسخهٔ رکورد از بازنویسی هم‌زمان تغییرات جلوگیری می‌کند. عبور به بررسی محتوا به ثبت بررسی حریم خصوصی نیاز دارد و دریافت گزارش به ثبت تصمیم بازبین وابسته است.
اصل فایل از صفحهٔ رکورد قابل دریافت است. بازگرداندن محتوا برای اصلاح یا تغییر اطلاعات بررسی، تصمیم فعلی بازبین را باطل می‌کند.

## دامنهٔ نسخهٔ اولیه

استخراج متن از قالب‌های پشتیبانی‌شده و تصاویر فارسی و انگلیسی فراهم است. برای صدا، ویدئو و قالب‌های فاقد استخراج‌کننده، متن‌خوانی دستی در دسترس است. بررسی امضای قالب و هش فایل و پیش‌نمایش پوشاندن اطلاعات شخصی متن در آماده‌سازی قابل اجراست. ضدبدافزار ClamAV با قرنطینه، پوشاندن خودکار چهره و پلاک در تصاویر ثابت و دسترسی پرونده‌ای فعال‌اند. پیشنهاد خودکار ارتباط پرونده‌ها و قواعد نگهداری خودکار هنوز پیاده‌سازی نشده‌اند. راهنمای جزئیات در [امنیت فایل و دسترسی](docs/FILE_SECURITY.md) است.

## سرویس‌های آنلاین

مدیر در بخش سرویس‌های آنلاین می‌تواند OpenAI یا OpenRouter، شناسهٔ مدل و کلید API مربوط را ثبت کند. جست‌وجوی منابع عمومی به کلید Brave Search نیاز دارد. کلیدها در پایگاه دادهٔ فضای محلی ذخیره می‌شوند و از API خوانده نمی‌شوند. تحلیل تنها با دکمهٔ ارسال متن و جست‌وجو تنها با ارسال عبارت جست‌وجو اجرا می‌شود. پیشنهاد تحلیل و منابع ابتدا در فرم قرار می‌گیرند و پس از بررسی و ذخیرهٔ کاربر ماندگار می‌شوند.

اتصال‌ها براساس [Chat Completions در OpenAI](https://developers.openai.com/api/reference/resources/chat)، [Chat Completions در OpenRouter](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion) و [Brave Web Search](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started) پیاده‌سازی شده‌اند.

## آزمون

آزمون مستقل چرخهٔ جدید، ثبت اولیه، انتقال مرحله‌ها، تعارض نسخه، استخراج متن، الزام بازبینی، خروجی و ماندگاری داده را بررسی می‌کند.

```sh
python -m pytest tests/test_workflow_reset.py -q
```
