# ساهر؛ گردش کار محتوا

رابط جدید بر مبنای چهار مرحلهٔ ورودی، آماده‌سازی، بررسی محتوا و خروجی و بازبینی طراحی شده است.

## اجرا

در ریشهٔ پروژه اجرا کنید.

```sh
docker compose up -d --build --wait
```

نشانی برنامه در اجرای محلی به شکل زیر است.

```text
http://127.0.0.1:8730/
```

## مسیر فعلی

۱. فایل همراه منبع و مجوز پردازش ثبت می‌شود.
۲. کاربر نتیجهٔ بررسی سلامت و حریم خصوصی را ثبت می‌کند و متن را استخراج یا دستی وارد می‌کند.
۳. موضوع، پرونده یا رویداد مرتبط، شواهد و موارد نامشخص ثبت می‌شوند.
۴. قالب بررسی، نام بازبین و دلیل تصمیم ذخیره می‌شوند و گزارش ساختاریافته قابل دریافت است.

اصل فایل، متن، مشخصات و تاریخچهٔ تغییرات در فضای پایدار داکر نگهداری می‌شوند. نسخهٔ رکورد از بازنویسی هم‌زمان تغییرات جلوگیری می‌کند. عبور به بررسی محتوا به ثبت بررسی حریم خصوصی نیاز دارد و دریافت گزارش به ثبت تصمیم بازبین وابسته است.

## دامنهٔ نسخهٔ اولیه

استخراج متن از قالب‌های پشتیبانی‌شده و تصاویر فارسی و انگلیسی فراهم است. برای صدا، ویدئو و قالب‌های فاقد استخراج‌کننده، متن‌خوانی دستی در دسترس است. پوشاندن خودکار چهره و پلاک، جست‌وجوی برخط منابع عمومی، پیشنهاد خودکار ارتباط پرونده‌ها، مدیریت دسترسی چندکاربره، تنظیمات قابل ویرایش و قالب‌های نهایی ورد هنوز به پیاده‌سازی نیاز دارند. خروجی فعلی یک پروندهٔ ساختاریافته است.

## آزمون

آزمون مستقل چرخهٔ جدید، ثبت اولیه، انتقال مرحله‌ها، تعارض نسخه، استخراج متن، الزام بازبینی، خروجی و ماندگاری داده را بررسی می‌کند.

```sh
python -m pytest tests/test_workflow_reset.py -q
```
